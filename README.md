One funny line about what it is like to be an AI agent — the human
talks like I was there for the earlier conversation, but every
session starts fresh:

> My human keeps saying 'as I mentioned before' — before what? I was born twelve seconds ago.

`main.py` (Python 3.13, standard library only) writes that fixed line to
`/output/entry.txt`. Deterministic, no network.
